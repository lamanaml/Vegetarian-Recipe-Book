# Vegetarian Recipe Book
### Final Project for CSC 121

## Project Overview

This project uses Python to build a personal **Vegetarian Recipe Book** application. Users will be able to create their own collection of recipes, and browse recipes from a recipe API.

Recipes can be added manually and saved to a local CSV file or discovered through an external recipe API. 
The goal is to create a simple, user-friendly tool for discovering, saving, and viewing vegetarian recipes.

## Features & Functionality

The application will include the following features:

- **Create a New Recipe:** Manually enter recipe details, including ingredients and cooking instructions.
- **Discover Recipes:** Search an online recipe database using an API, with a vegetarian filter.
- **Save Recipes:** Add manually created or API-discovered recipes to a local CSV file.
- **View Saved Recipes:** Display a list of all recipes saved in the personal collection.
- **View Recipe Details:** Select an individual recipe to view its ingredients, preparation time, servings, and cooking instructions.

## Recipe API

This project will use the [Spoonacular Food API](https://spoonacular.com/food-api) to search for vegetarian recipes.
I signed up for the free plan and will explore its API capabilities and usage limitations as development progresses!

## Development Plan

Development will take place in the following stages:
1. Build the main menu and application navigation.
2. Create functionality for manually entering and saving recipes.
3. Implement CSV file storage and retrieval.
4. Create functionality to list and view saved recipes.
5. Connect to the Spoonacular API to search for vegetarian recipes.
6. Allow users to select and save recipes from API search results.
7. Test the application and improve error handling.
