# Vegetarian Recipe Book
### Final Project for CSC 121


## Project Overview


This project uses Python to build a personal **Vegetarian Recipe Book** application. Users will be able to create their own local collection of recipes and browse recipes from a recipe API.


The goal is to create a simple, user-friendly tool for discovering, saving, and viewing vegetarian recipes.


## Features & Functionality


The application will be able to:
Create and save a new recipe to a local file
View saved recipes
Find new recipes using an api
