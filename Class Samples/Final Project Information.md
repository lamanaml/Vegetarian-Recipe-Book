## Project Overview & Options

The final project is broken up into three sections:
1. **Planning** (Week 14)
2. **Code and Demo** (Week 15)
3. **Recap** (Week 16)

You have **two options** for your project:
* Get the `book_tracker` CLI tool into a state that accomplishes all requirements.
* **OR** create a new personal Python application (`.py` file) that meets all requirements.

### Core Project Requirements
We will be creating a new **Private GitHub Repo** for your personal project. Your project must include:
* **Repository:** Its own Private GitHub Repo.
* **User Interface:** An intuitive menu with options that can be selected.
* **Data/API:** Call an API using the `requests` library **AND/OR** use File I/O.
  * **MAJOR NOTE:** If you are using an API, ensure that you **never push your API key to your repo**. This is what `.gitignore` is for. Save your API key locally only in a `.env` file and never push this to the repo. You will also need to include the `python-dotenv` library (details at [PyPI: python-dotenv](https://pypi.org/project/python-dotenv/)).
* **OOP:** At least one class that is used.
* **Search:** A search feature using Regular Expressions (`regex`).
* **Testing:** A set of tests.
* **Professionalism:** A topic that you would be comfortable with a future employer seeing.
* **Documentation & Demo:** A PDF detailing your Planning step, and a video demo showing you using your app and describing the different features.
